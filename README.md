# Sweet Symphony sounds

Sound banks that [Sweet Symphony](https://github.com/jaimecojab4-oss) downloads the first time an
instrument needs them (Track > Add Instrument Track...). The files are in this repository's
**Releases**; each one keeps its own license, copied unchanged in `licenses/`.
